## 🌟 Highlights & Dual-Personality Architecture

This portfolio features an interactive dual-personality design:

1. **Creator Mode (Light Mode)**:
   - **Hero Interactive Elements**: Draggable Canva text boxes for *"Marvin"* (violet) and *"Marketer."* (blue) with live handles and double-click reset.
   - **Multiplayer Cursors**: Floating collaborator cursors (*Creativity*, *Technology*, *Business*).
   - **Infinite Marquee**: "As Seen On" partner ticker with high-growth ecosystem logos (DOST PUP TBI, Costify, Samsung Galaxy Campus, AWS Cloud Clubs, etc.).
   - **Videos & Vlogs**: Clean modal-ready video hub (*I REVIEW*, *I RUN*, *I WORK*).
   - **Perks & Vouchers**: 1-click clipboard promo code cards for Samsung Student Store, AWS Builder Credits, and Costify.
   - **Samsung Galaxy Campus**: Interactive device showcase across Galaxy S, A Series, and Ecosystem.
   - **Samsung Community Articles**: Full-width editorial cards featuring *Galaxy Rewind* (S & A series) and *Galaxy S26 Ultra* first impressions.

2. **Executive Mode (Dark Glow Mode)**:
   - **Interactive 3D Flip Portrait**: Seamless Y-axis flip revealing Marvin's executive formal suit portrait with cyberpunk glow and verified HUD brackets.
   - **Portfolio Showcase (Our Work)**: Data-backed case studies with animated counters:
     - **Costify (DOST PUP TBI)**: 8M+ Views, 3.9K+ Purchases, ₱1.75M+ Revenue in 5 months.
     - **Samsung Galaxy Campus SEA&O**: 20M+ Impressions, 15+ Campus Hubs, 3× Series Campaigns.
     - **AWS Cloud Club PUP**: +300% Member Growth, 1.2K+ Students, 14 Workshops.
   - **Branding & Visual Systems**: Creative direction and typographic design decks.
   - **Strategic Approach**: 4-step framework (*Data-Driven Hook*, *Viral Mechanics*, *Ecosystem Distribution*, *Metric Optimization*).
   - **Career Timeline & Endorsements**: Leadership milestones and peer recommendations.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS3**: Custom design system, CSS Grid/Flexbox, 3D perspective transforms, HUD brackets, and dark glow effects.
- **JavaScript (ES6+)**: Interactive controllers, mode switching, draggable Canva physics, numbers counting engine, and modal popups.
- **GSAP & ScrollTrigger**: Smooth entrance choreography and scroll animations.
- **Node.js**: Zero-dependency local development server (`server.js`).

## 🚀 Quick Start

To run locally:

```bash
# Clone the repository
git clone https://github.com/vinbitz/vin.barrios.portfolio.2026.git
cd vin.barrios.portfolio.2026

# Start the local server
node server.js
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.
